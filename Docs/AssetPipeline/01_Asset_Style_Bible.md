# Asset Style Bible

版本：0.1 · 草案，待批准

> 2026-10-29 方向更新：用户明确要求世界偏体素风格，与现有人物的几何块面及像素纹样统一。下文「不是 voxel」属于旧方向，不再作为排除规则。当前视觉参考与人工筛选记录见 `StyleLibrary/README.md`、`StyleLibrary/catalog.json` 与 `StyleLibrary/reviews.json`；最终样式以用户设定的核心图片参考为准，不能只用文字决定。

## 风格定位

**Soft Stylized 3D Chinese Fantasy**，用于中国仙侠 / 武侠 3D ARPG。

**Recognizable Form · Expressive Character · Simplified Surface**：形态可辨识，表演有生命，表面做减法。

《仙剑奇侠传三》作为人物比例、仙侠感和角色表现力参考；Sokpop《White Lavender》作为简化几何、清晰大形、低视觉噪声和地图整体感参考。本项目不是 voxel，也不直接复制高度抽象的 Low-Poly 风格。

## 判断优先级

1. **P1 轮廓与形态识别**：纯灰材质、关闭贴图后，仍能识别资产类别和主要结构。刀、剑、弓应区分；伞、香炉、树、石头、建筑、角色与敌人应可辨识。识别不能主要依赖复杂纹理。
2. **P2 角色表演**：角色允许高于环境的复杂度。优先保留眼睛、眉毛、嘴部、面部表情、身体语言、关节变形、攻击动作，以及头发、袖摆、配饰的动态轮廓和武器互动。不得为了减面破坏表演。
3. **P3 文化识别**：保留承担识别、叙事或文化表达的结构与细节。传统资产不自动获得高精度预算；重复装饰与表面噪声可以提出简化建议，但由人工决定。

## 几何与表面

几何预算依次优先用于轮廓、角色变形、面部表情、可辨识结构、重要文化形态。不可见内部结构、AI 碎片、重叠几何、无意义凹凸和微小表面细节列为审查对象，不能仅凭尺寸自动删除。

表面复杂度应明显低于形态复杂度。优先大色块、哑光材质、受控粗糙度、简单风格化贴图与清楚的材质分区。减少写实木纹、细小划痕、污渍噪声、密集裂纹、毛孔、过强法线和随机粗糙度变化。特别检查“几何已风格化，贴图仍写实”的不一致。

## 类别取舍

| 类别 | 优先保留 | 提出简化审查 |
|---|---|---|
| Character / Enemy / NPC | 轮廓、脸、表情、动作、衣物大形 | 皮肤与织物微细节、逐根发丝 |
| Weapon | 刀/剑/弓类别、握持区、轮廓、主要结构 | 划痕、微小装饰 |
| Cultural Prop | 传统形态与有意义细节 | 重复装饰噪声 |
| Normal Prop | 物体识别与交互部位 | 表面噪声 |
| Vegetation | 树种轮廓、主枝 | 逐片叶子、细小枝条 |
| Terrain | 构图、导航、空间大形 | 微小几何 |
| Rock / Snow | 材质身份、轮廓 | 写实裂纹与噪声 |
| Architecture | TBD；屋顶、斗拱等特色结构需人工确认 | TBD；不得自动强制简化 |

油纸伞通过伞盖、伞柄、必要伞骨和比例被识别；香炉通过炉身、炉足、炉耳和炉盖被识别。具体纹样是否重要由人工判定。

## 首个环境：山林雪地

环境服务空间层次、导航、氛围与构图。视觉层级为：**简洁环境 → 可读交互物 → 富有表演的角色**。

覆盖雪地、山体、松树、枯树、岩石、悬崖、路径、石碑、亭阁/小型建筑、香炉、伞、NPC 与敌人。以实际游戏镜头检查可读性，而不是只看模型近景。

## Golden Reference Set

初始候选：主角、剑、敌人、松树、岩石、香炉、传统伞、石碑、雪地、小亭。候选经人工批准后才成为 Golden，附批准人、日期、版本、参考截图及适用范围。

Golden 是受保护参考，**不得自动修改**。新版本从副本产生，经重新批准后纳入；旧版本保留。

## 判断职责

人类 / 美术负责人决定风格、轮廓、比例、文化真实性、视觉层级、表情、动画感受与接受/拒绝。Tripo 生成候选；Blender 负责清理、优化、材质、变换、轴心与导出准备；Codex 负责技术规则、重复自动化、命名、报告和适当的 Unity 工具。

自动报告不能声称已判断艺术质量。所有视觉判断输出 **MANUAL REVIEW REQUIRED**，由人工签核。
