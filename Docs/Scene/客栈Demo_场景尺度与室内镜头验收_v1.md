# 客栈 Demo · 场景尺度与室内镜头验收 v1

日期：2026-11-03。当前灰盒采用 1 Unity 单位 = 1 米。以下是本 Demo 的制作尺寸，不作为历史建筑规范。人物设定优先于通用占位比例。

## 1. 人物基准（已确认设定）

| 人物 | 模型总高 | 碰撞体世界总高 | 宽度/直径 |
|---|---|---|---|
| 女主 | 1.60m | 1.60m | 视觉 0.54m、碰撞直径 0.54m |
| 同行者 | 1.70m | 1.70m（站立） | 视觉/碰撞直径 0.56m |
| 老板 | 1.75m | 1.75m | 视觉/碰撞直径 0.62m |

女主碰撞体根节点不缩放，中心为脚部上方 0.80m，视线为 1.48m，镜头注视高度为 1.30m。同行者站立中心为 0.85m，躺卧时按胶囊横卧半径放置。CharacterController 接触余量为 0.03m。

同行者当前碰撞体挂在有缩放的占位胶囊上，局部高度必须除以缩放，世界高度才是 1.70m；不能只检查 Inspector 内的 height 数字。未来导入角色模型时优先使用单位缩放的物理根节点，视觉模型作为子节点。

## 3. 室内镜头规则

- 普通第三人称后距 3.4m，右肩偏移 0.65m；注视高度按女主 1.60m 身高设置。
- 鼠标和方向键均保留原快捷键。俯仰范围 -15° 至 65°。
- 从人物注视点用 0.22m 半径球形检测到理想机位，排除女主、同行者、老板自己的身体碰撞，忽略 Trigger。
- 墙、门楣、家具、天花板都可使镜头拉近。遇到遮挡立即收紧，避免平滑过程中穿模；障碍离开后以约 0.28s 的平滑参数恢复距离。
- 极近时只隐藏女主占位网格：小于 1.05m 隐藏，大于 1.25m 再显示，避免阈值附近闪烁。人物碰撞和移动继续有效，不隐藏墙或屋顶。
- 门洞内高仰角时允许短暂进入近景；“不穿模”的检查不代表所有角度的距离都已达到最佳手感，仍需人工判断回拉、恢复和转角体验。
- 读档时重置镜头平滑状态，避免从旧位置横穿场景追过去。

## 4. 现有自动/脚本验证

Unity 菜单：Tools → Inn Demo → Validate Scene Scale And Camera（需要在 Play 中运行）。

- 校验净高、柜台高、三人设定身高、床长，以及女主/已醒同行者的碰撞体世界高度。
- 房间、走廊、门洞三个站位，各 8 朝向 × 4 俯仰角，共 96 个机位采样，检查机位周围不与建筑碰撞重叠。
- 角色碰撞移动：从双床房到单床房、二楼到地面再上楼。身高调整后同行者可从地面上楼，并通过双床房门，站立中心约为楼面 + 0.85m + 接触余量。
- 双人离店：同行者 1.70m 的实际碰撞体也能走过正门，两人脚部都跨线才结算。
- 剧情规则的九组合、顺序、真相计数和存档往返另由 Validate Narrative Rules 检查。

人工 playtest：普通视角穿过两个房门；走廊左右转；贴墙旋转；抬头看天花板；上楼和下楼；停在柜台前看老板；读档后镜头；唤醒同行者并带她下楼离店。主要反馈距离是否太近、回拉是否突兀、恢复是否太慢、模型重现是否明显。
