# 客栈外景高斯摆放方案

建议试用 `Tools/Aholo/outputs/江南古镇-Toon.spz`。它的参考全景有沿河店面、石桥和石铺岸边，可以接在现有客栈门外的石铺地之后。文件实测约 7.85 MiB，480,190 个高斯点。另两份是江南古镇原版（7.83 MiB）和竹林（7.10 MiB）。

| 元素 | 首次试摆 |
| --- | --- |
| 客栈正门 | 沿用 (0, 0, -10)，门宽 2.8 米、高 2.6 米 |
| 门外近景 | Unity 石铺地延伸到 Z=-16.2，正门中轴留通行 |
| 高斯前缘 | 在 Z=-16 至 -18 接岸线及店面，用码头石阶或矮栏遮接缝 |
| 桥与河道 | 桥放在出门后的斜前方，先试桥心 X=6–9、Z=-23 至 -28，岸面与 Y=0 对齐 |
| 初始覆盖 | 主景宽约 40–50 米，进深约 25–35 米。沿岸街道可斜对客栈门轴，试偏转 20–35° |

导入后选靠近接缝的一段岸边石板和一处店面门洞作标尺。以门洞实测高度映射约 2.4 米得到统一 scale，再用岸边石板和桥净宽复核。用岸边接点计算平移，让岸面落在 Unity 的 Y=0，接点对到 Z=-17 左右。高斯文件的坐标范围受远处点影响，仅用于检查异常尾点。按主景裁剪后再定最终 scale 和旋转。

当前项目的包清单中未看到高斯 renderer。先在独立外景预览场景验证支持 SPZ v3 的 URP 渲染方案，分别拍门槛向外、院中侧看、出门回看。客栈和可走岸边的深度、碰撞及角色遮挡由实体网格负责。用同设备比较开启高斯前后的 CPU/GPU 帧时和显存，再考虑裁掉室内穿帮点与岸边浮点。高斯试摆参数需等导入后用实际锚点校准。
