# 室内布局与梁板顶提案 v4

## 采纳与适配

采纳右侧单跑直梯、临空木栏杆、厚横梁与次梁、木板顶、一楼灰石地面、二楼木地板、柜台后收纳架、桌配长凳的古朴气质。参考图的尺度和透视不作为20×30m工程测量依据。

楼梯保持既有x约4m、宽2.40m、24级、南低北高的直梯结构，暂不照图贴到东墙，以免重新牵动平台、背景客房和通行逻辑。补木质梯侧梁、踏板、竖栏杆和扶手，视觉件不可侵占原净宽。

二楼走廊靠实体墙/房间侧不必添栏；所有临空边及平台开放侧加1.20m木栏杆，楼梯入口必须断开，通道不被围死。现有灰盒已有栏杆碰撞，本轮是明确其视觉样式，不代表原工程完全没有护栏。

大堂图纸建议4组餐桌：西侧3组、东南1组，均框线占位、配长凳。中央入口至大堂后部保留约2m主通道，楼梯前和柜台调查面留出通行区。后东北柜台保留，背架择不堵窗墙段或采用低架。此为待审布局；若进入工程，涉及既有桌子/藏令物件的移动，必须联动锚点并重新验收，不能把概念图改动直接当作已落地。

## 天花板

建议先采用平顶梁板结构：深棕木板为顶面、粗横梁控制开间、较细次梁形成节奏。优先嵌入/利用既有顶板0.30m厚度，梁底不低于8.50m、板面在梁底上方，使视觉立体化而不降低现有镜头净空。具体板厚、梁高需建模复核，不能声称是历史结构设计或承重计算。

参考图中可见的斜屋架可作为未来方案，但完全去掉平顶、开放屋顶空间属于结构与镜头碰撞调整，需要独立验收；本版不默认采用。大堂上方挑空区、二楼客房及走廊顶部都保持封顶；一楼被二楼覆盖区域看到的是楼板底面，不能画出穿过二楼房间直达屋架的假挑空。
