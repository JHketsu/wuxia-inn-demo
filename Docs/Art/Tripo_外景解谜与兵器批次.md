# Tripo 外景、解谜与兵器批次

余额按用户给出的 3000 Studio 积分规划。以下为批次上限，可以剩余。实际按网页提交报价记账。后厨陈设退出本轮。

| 批次 | 目标 | 预算上限 |
|---|---|---:|
| 解谜关键件 | 药箱、带旧镖号的剑鞘、账本、手令纸、撕口药包 | 350 |
| 客栈外景 | 驿路木牌、界碑、拴马桩、手推车、路边酒坛、篱笆端件、行旅货筐、石灯台 | 500 |
| 植被 | 稀竹丛、低矮灌丛、枯草簇、蕨丛、藤蔓段、路边小树 | 350 |
| 十八般兵器 | 每种一件独立网格 | 850 |
| 自创武器 | 蝴蝶刃、惊鸿武神弓 | 250 |
| 机动 | 已验收高优先级资产的返修与变体 | 700 |

先选药箱、稀竹丛和两件自创武器做样品，验证轮廓、材质、导入尺寸和实际镜头。关键道具沿用既有调查位置与逻辑，文书正文和镖号由 Unity 材质或 UI 单独制作。药箱按源码 XYZ 0.50 × 0.30 × 0.40 m，盒盖可分件。植被优先测试剪影及同组多实例性能，细叶适合用简单叶片或卡片，风动后续在 Unity 做。外景先铺客栈门前到路口的可见范围。

统一提示尾段：古朴中式武侠游戏道具，清晰块面，深色铁、旧木、缠布与少量旧铜，低饱和，轮廓易读。画面内只有一件完整物体，白底，中性柔光，无人物、字、展台、其他武器。挂墙或持握的轴向与枢轴在 Unity 整理。流星锤链条、弓弦优先考虑独立几何，方便替换或后续动画。

自创武器视觉提案：蝴蝶刃为单把短刃，用旧铜蝶翼护手构成识别点。惊鸿武神弓为红褐木反曲弓，用燕翼状弓梢、旧铜与飞燕纹表现造型。两件均先做单物件图生网格。
