# 《荒夜客栈》千禧江湖 UI 设计原则

本页记录探索 HUD 与对话的视觉规则，供 Figma 和 Unity 交接。同行者客房预览用于参考构图、材质和装饰。预览字号和字形比例不作为规范。

- **主框借用窗棂的构造。** 对话框与任务面板用墨蓝底和银灰双细线。四角用短直线折回，像中式木窗棂的转角接合。图中的纹样可解读为窗棂与简化回纹的结合。转角是装饰重点，长边留直，避免通栏重复纹样。
- **小框借用嵌牌的轮廓。** 姓名牌和菜单按钮以横向矩形为基底，四角切出短阶梯，再以内描边勾出嵌边。暗朱红用于姓名牌和菜单入口，银灰延续大框的边线。姓名牌是静态标签，菜单入口使用双卷合拢的卷轴图标与「菜单」文字，右侧用小箭头提示展开。卷轴是一张纸从两端向内卷起，两卷并排，中缝可见相连的纸，两端的纸卷层次在小尺寸下也应清楚。按钮提供默认、悬停、按下和键盘焦点状态。
- **立绘采用无框融入。** 2D 胸像完整收在对话面板右侧，肩部自然过渡到墨蓝底，发顶与外框之间留空。正文使用独立区域，长句换行也避开立绘。不同角色共用面板，通过姓名和立绘识别说话人。
- **探索时保留场景视野。** 左上显示当前目标与下一步，右上保留菜单入口，快捷键说明在展开后出现。底部面板随对白或心想出现。顶部中央留给场景。
- **字号按实际内容定。** 标题可以保留宋体气质，正文优先保证字形清楚。用长任务、短对白和多行对白在 1920×1080 与 1280×720 上检查，再确定字号、行高和边距。Figma 中将正文、姓名和快捷键保留为可编辑文字，框线与装饰独立成组件。
