# 荒夜客栈 · 剧情 v1

Unity 6000.0.60f1。打开 Assets/Scenes/SampleScene.unity 并 Play；灰盒与交互在运行时生成，退出 Play 后不保留运行时几何体。设计来源：项目根目录 Docs/Narrative/客栈Demo_剧情与探索设计交接_v1.md。

## 操作
WASD 移动；鼠标或方向键控制镜头（←→ 旋转，↑↓ 俯仰）；Shift 快走；走近显示 E 后交互，再按 E 关闭（同帧不会重新打开）；仍可点击关闭按钮或 Esc；点击对话选项；Q 凝神观察，显示同层、视线可达的 6 米内热点 4 秒；Tab 收起/显示当前任务；J 调查记录；F 在门边撞断旧门闩（无需剑）；F5 单槽存档；F9 读取；Ctrl+R 重新开始，通关后可直接 R。建议放大 Game 窗口。

## 第一轮：最短流程
1. 二楼可先看己方杯子、行李、药笺。从东侧楼梯下楼。
2. 大堂蓝衣同行者旁 E 检查，去柜台前 E 找老板，选择求助。
3. 回二楼，穿过隔墙中间门洞，检查客房的药粉和残食。
4. 下楼到柜台右侧药箱，领取对应解药和绷带。
5. 回同行者处，请老板协助救治。若想独自救治，先读二楼己方床边药笺。
6. 回老板处，选择 S3 夺取，并明确确认。不需要手令或旧账。
7. 在同行者或出口对话里确认 P1 亲自履约。
8. E 开门或 F 撞门，等同行者跟上，一同越过门槛。

## 第二轮：调查与分支
- 大堂桌边血迹 → 桌底松木条 → 明确翻查取得手令 → 阅读 → 醒后请她辨认 → 归还或征询代管。三者分开记录。
- 柜台血滴与手伤 → 问老板昨夜经过；柜台最右侧剑鞘与旧账 → 追问旧事。
- 问同行者昨夜行动、改貌和用餐，再与老板核对下毒先后；顺序可交换。
- S1：救醒、问清老板旧事、向她明确尊重意愿，再向老板请求托付。
- S2：救醒、查旧账、听老板交手证词，再向老板追责取剑。
- S3：救醒即可明确威逼取剑，仍需确认。
- P1 无手令门槛；P2 先问她为何隐瞒/担忧转交；P3 读过手令并与她明确确认。
- 三种剑与三种约定可任意搭配，离店前能重谈约定。差异在当场对白和出口收束中出现。
- 威胁老板后他停止协助，但药箱开放；读药笺可独自救治。公开指控后可听证词并向老板修正判断。
- J 显示八项真相的未知/存疑/已确认，物证与证词分别记录，重复调查不增加计数。真相数量不是善恶评分，也不阻挡通关。

## 当前验证边界
已通过 Unity 编译和运行检查，状态层九种 S×P 组合、最短合法路线、真相去重及 JSON 往返检查。通过 MCP 调用实际对话按钮行为，完成协助救治、S3、P1 和双人出口通关。11 个热点均在采样站位命中近距离交互判定；不是逐步键鼠导航测试。F5/F9 实际恢复醒来、S1/P3、手令与真相记录；测试保留了原有用户存档。
