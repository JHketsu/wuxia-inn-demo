# 荒夜客栈｜女主武侠解谜 Demo

一个以客栈为舞台的第三人称叙事解谜原型，也是用 AI 协作推进游戏设计、开发与美术接入的实践记录。

女主清晨醒来，原本要继续护送受伤的同行者上路，却发现旁边床位空了。楼下有血迹，同行者昏迷，老板在柜台后擦剑。玩家需要探索客栈、救醒同行者、取得剑，再一起离开。调查的顺序、对话与行动，会改变玩家理解的真相、取剑方式和两人离店时的约定。

当前使用灰盒与占位资产，重点验证探索、叙事分支、跟随、室内镜头和阅读体验。正式角色、动画、音效和美术仍在后续计划中。

## 运行工程

使用 **Unity 6000.0.60f1** 打开 `游戏工作区/wuxia`，加载 `Assets/Scenes/SampleScene.unity` 并进入 Play。灰盒场景与交互在运行时生成，退出 Play 后不保留运行时几何体。首次打开需要 Unity 下载依赖包。

WASD 移动，鼠标或方向键控制镜头；E 交互与关闭，Q 凝神观察，J 手记，Tab 任务，F5/F9 存读档。完整说明见工程内试玩文档。
